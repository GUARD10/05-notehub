# NoteHub

Personal notes workspace built with React, Vite, TanStack Query, Formik, and Yup.

## Setup

```bash
npm install
cp .env.example .env
```

Add your personal token to `.env`:

```env
VITE_NOTEHUB_TOKEN=your_token
```

Get the token in the [NoteHub API docs](https://notehub-public.goit.study/api/docs).

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run format
npm run typecheck
```

## Stack

- React + TypeScript + Vite
- TanStack Query
- Axios
- Formik + Yup
- react-paginate
- use-debounce
- CSS Modules + modern-normalize
